# i-love-me.ru

Сайт справочника mesoestetic (GitHub Pages).

- `/` — страница скачивания приложения (вариант «Орбита»), собирается скриптом `tools/build_landing.py` из данных справочника `grudnyaks/mesoestetic-guide_ru`.
- `/diagnostika/` — диагностика age element (в работе).
- `/brand/` — о бренде (в работе).
- `img/` — экраны приложения, иконки, превью для соцсетей.

Справочник (веб-версия) — app.i-love-me.ru, репозиторий `mesoestetic-guide_ru`.
